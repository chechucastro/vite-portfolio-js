# Vite Portfolio JS

Personal portfolio project built with vanilla JavaScript and Vite.

## Production Demo

- https://vite-portfolio-js.pages.dev/

## Tech Stack

- JavaScript (ES Modules)
- Vite
- HTML5
- CSS3

## Main Features

- **About me** section with personal info and skills.
- Dynamic content section that toggles between **Education** and **Experience**.
- **Projects** section with project cards.
- Avatar interaction (rotation animation on click).

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview production build:

```bash
npm run preview
```
